# Verification report — chondrotwin 0.3.0 (re-run and confirmed on 0.9.0)

This report documents what was checked before the release that accompanies the manuscript, what was found, and what
was changed. It covers **verification** (the code solves the stated equations correctly, results are reproducible,
and every quantitative statement in `README.md` and `docs/models.md` follows from the code) and a **plausibility
check** of the biological and physical assumptions against primary literature. It is *not* a validation against
experimental data: all parameters are illustrative and uncalibrated (in ASME V&V 40 terms, no context of use is claimed).

Everything below is regenerated by

```bash
python scripts/validate.py --out validation_results.md   # ~8 min; --quick skips the multi-seed runs (~1 min)
pytest                                                   # 65 tests in 0.9.0
```

Re-run on 0.9.0 (all sections identical except the memory per slot, which grew with the optional per-cell fields).
Reference environment: Windows 11, Python 3.11.9, NumPy 2.4.6, SciPy 1.17.1, pandas 3.0.6, Matplotlib 3.11.2
(clean virtual environment, `pip install -e ".[dev]"`). CI runs the tests and `validate.py --quick` on Linux with
Python 3.9, 3.11 and 3.13.

## Corrections in 0.3.0

Code

* `boolean.py` — SOX9 rule now `… ∧ (TGFb ∨ PTHrP ∨ ¬WNT)`. Before, the growth-plate attractor labelled
  "proliferative (PTHrP-held)" had SOX9 *off*, contradicting the biology (PTHrP/PKA phosphorylates and activates SOX9;
  Huang et al., PNAS 2001) and the repository's own Figure 2 ("Proliferative zone (SOX9, COL2A1 …)"). The change
  alters only that row of the attractor table (active nodes "none" → "SOX9"); all other attractors, labels and basin
  fractions are identical.
* `growth_plate.py` — default integration horizon 12 → 40 (early stop on convergence). At 12 the Jansen-like
  variant did not meet the convergence tolerance (`converged = False`); the boundary value was already correct.
* `landscape.py` — returns `crossed` (fraction of walkers that crossed between basins) and accepts
  `start_fraction_sox9`; the quasi-potential itself is unchanged (bit-identical for the defaults).
* `abm/scaling.py` — memory constants and whole-knee estimate corrected (measured values, §9).

Manuscript figure

* Figure 5 of the manuscript (schematic script, since removed from the repository; the corrected version is in the git history of 0.9.0), inflammation box: "IL-1β → PI3K/AKT/mTOR → Piezo1↑" corrected to
  "IL-1α → p38 MAPK (HNF4, ATF2) → Piezo1↑". In Lee et al., PNAS 2021 (the source of the inflammatory Piezo1
  sensitization), IL-1α up-regulated Piezo1 through p38 MAPK and the transcription factors HNF4 and ATF2/CREBP1, and
  PI3K inhibition did *not* block it. **The manuscript text should be checked for the same statement.**

Documentation: `README.md` and `docs/models.md` updated as listed in the table; literature sources for the
Boolean wiring added to `docs/models.md`.

## Literature checks of the network wiring

Piezo1/Piezo2 in high-strain injury (Lee et al., PNAS 2014); TRPV4 in physiological loading (O'Conor et al., PNAS
2014); inflammatory Piezo1 sensitization via p38 MAPK (Lee et al., PNAS 2021); reciprocal YAP/TAZ–NF-κB inhibition
and TNF-α/IL-1β-induced, TAK1-mediated YAP/TAZ degradation (Deng et al., Nat Commun 2018); HIF-2α as a catabolic /
hypertrophic regulator (Saito et al., Nat Med 2010; Yang et al., Nat Med 2010); GPX4-regulated ferroptosis after
mechanical overload via Piezo1-mediated Ca²⁺ influx (Wang et al., J Adv Res 2022); SOX9 as a target of PTHrP
signaling (Huang et al., PNAS 2001); quasi-potential U = −ln P (Wang et al., PNAS 2011). The AI tools named in
Figure 8 (SAMRI-2, KneeXNet-2.5D, KneeSeg-U) exist as published knee-MRI segmentation methods.

## Open points (not changed; for the authors to decide)

* **Langevin landscape.** For a stationary quasi-potential at λ ≠ 0, either raise the noise / run time until walkers
  equilibrate between basins (`crossed` → large), or report basin-conditioned (local) barriers only. The diagnostic
  figure `landscape_langevin.png` (σ = 0.18) shows correct escape barriers but not correct relative basin depths at λ = 0.35.
* **ABM cell density.** Default 1.4e4 mm⁻³ vs 9.6e3 mm⁻³ (Hunziker et al. 2002). Fate fractions are relative and the
  cytokine source is normalized to the reference density, so results should change little, but this was not re-run.
* **ABM hypertrophic fraction.** RUNX2-high cells appear transiently (up to 41 % in sustained overload) but at day 365
  nearly all of them have become senescent or died (final hypertrophic fraction ≤ 0.4 %). If the manuscript describes a
  persistent hypertrophic population in OA-like cartilage, the hazards would need to depend less on overload alone.
* **Manuscript text vs code.** Figures 2 and 4 are produced by the package; the manuscript's numerical statements
  (e.g. λ window, boundary positions) should match the values above.
